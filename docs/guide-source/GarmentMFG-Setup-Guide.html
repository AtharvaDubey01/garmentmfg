Setup Guide

Garment production & payroll · how to install it and start using it

1What you get

One file: GarmentMFGSetup.exe. It contains everything — the program and its own private database. Nothing else needs to be installed.

GarmentMFG is installed on one PC only (the server PC). Every other PC in the office just opens GarmentMFG in a web browser — nothing is installed on them.

2Before you start

  • Pick the server PC: Windows 10 or 11 (64-bit), on the office network, and one that stays switched on during working hours.
  • You must be able to click "Yes" on the Windows administrator prompt on that PC.
  • About 1 GB of free space on the drive you install to.

3Install (about 5 minutes)

  1. On the server PC, make a new folder for GarmentMFG, e.g. D:\GarmentMFG (a fixed drive — not a USB stick).
  2. Copy GarmentMFGSetup.exe into that folder.
  3. Double-click GarmentMFGSetup.exe.
  4. If a blue box says "Windows protected your PC", click More info, then Run anyway. (It appears only because the file is not signed yet; it is safe.)
  5. Click Yes on the Windows prompt (this gives it permission to install).
  6. A window shows the folder — press any key to continue.
  7. Wait about a minute. When it finishes it shows two web addresses. Done.
A GarmentMFG shortcut is placed on the desktop. Do not move or rename the GarmentMFG folder afterwards.

4Open GarmentMFG

WhereAddress
On the server PC itselfhttp://localhost:6060 (or the desktop "GarmentMFG" shortcut)
On any other office PChttp://SERVER-IP:6060  e.g. http://192.168.1.33:6060

Find the server PC's IP address (on the server PC): open Command Prompt, type ipconfig and press Enter. Look for IPv4 Address under your Wi-Fi or Ethernet — a number like 192.168.1.33. (Not "Default Gateway": that is the router.) Every other PC then uses http://192.168.1.33:6060. Open that address in Chrome/Edge on each employee PC and save it as a bookmark or desktop shortcut.

Keep the address the same: the router can give the server PC a different number after a restart, and then the bookmarks stop working. Ask whoever looks after the router to reserve this number for the server PC (often called "DHCP reservation" or "static IP" in the router settings). If an address ever stops working, check ipconfig again on the server PC.

6Make it yours: company name and logo

Set your company's name and logo once, and they appear on the login page, the menu, the home page, printed Job Orders and Lot Operation sheets, and report exports.

  1. Log in as ADMIN and open Admin → Company Branding.
  2. Type your Company name (e.g. "ABC Garments (P) Ltd").
  3. Click Choose logo… and pick your logo (PNG or JPG — a PNG with a see-through background looks best). Big pictures are made smaller automatically.
  4. Click Save. Until you do this, the app shows the GarmentMFG name and logo.

7Everyday use & data safety

  • Always on: GarmentMFG starts automatically with Windows and keeps running in the background — staff just open the web address and log in.
  • Automatic backups: GarmentMFG backs up all your data by itself, every day, and keeps six months.
  • Report headings: when you export a report to PDF, Excel or Print, a small box lets you type the title (and a second line) for the top of the report; your logo is added to PDFs and printouts.
  • Keep your own copy: any time, log in as admin → Backups → Download full backup to save one complete file (e.g. onto a pendrive).

8Updating to a new version

When you get a newer GarmentMFGSetup.exe, install it over the old one. All your data stays.

  1. (Recommended) Keep a copy first: log in as admin → Backups → Download full backup and save the file (e.g. onto a pendrive).
  2. Copy the new GarmentMFGSetup.exe into the same GarmentMFG folder on the server PC (e.g. D:\GarmentMFG), replacing the old file.
  3. Double-click it, and click Yes on the Windows prompt (and More info → Run anyway if the blue box appears).
  4. The window says "GarmentMFG will be UPDATED in this folder" — press any key to continue.
  5. Wait about a minute. It first saves a backup of all your data, then puts in the new version and starts GarmentMFG again.
  6. Refresh the browser on the office PCs. Everything is still there: job orders, entries, reports, logins and passwords, company name and logo.
Always run it in the same folder where GarmentMFG is installed. If you run it from another folder, it stops and shows you where GarmentMFG is — nothing is changed. To move GarmentMFG to another PC, ask your software support: they bring all the data across.

9Change the built-in passwords

Besides ADMIN, every installation has two built-in passwords. This public download uses the ones below, which anyone can read here — change both right after installing.
